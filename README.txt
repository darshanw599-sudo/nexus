NEXUS PRO — OFFLINE EXPENSE TRACKER

QUICK START
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Use the Transactions tab to add income and expenses.
4. Export JSON backups regularly.

PWA INSTALL / FULL OFFLINE CACHE
For installable PWA support and service-worker caching, serve the folder once over HTTPS or localhost, open it in Chrome/Edge, then choose Install. Service workers are not available from file://. The app itself runs locally and makes no network requests.

FEATURES
Dashboard charts, income/expense totals, category budgets, weekly/monthly recurring entries generated on app launch, PIN privacy lock, light/dark theme, CSV export, JSON backup/restore, print-to-PDF report, IndexedDB storage.

DATA
All data is stored in the browser's IndexedDB on this device. Clearing browser data may erase it. Export JSON backups regularly. PIN lock is a casual privacy barrier, not encryption.
